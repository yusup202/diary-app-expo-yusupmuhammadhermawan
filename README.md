### Langkah Menjalankan Proyek
1. Pastikan Node.js sudah terinstal di komputer.
2. Buka terminal di dalam folder proyek ini.
3. Ketik perintah `npm install` untuk mengunduh semua dependensi (`node_modules`).
4. Ketik perintah `npx expo start` untuk menjalankan server.
5. Buka aplikasi Expo Go di HP, lalu scan QR Code yang muncul di terminal.

### Fitur yang Diselesaikan
- Membuat struktur folder modular (`src/components` dan `src/screens`).
- Menampilkan daftar cerita diary menggunakan komponen `ScrollView`.
- Memisahkan desain kotak cerita menjadi *reusable component* (`DiaryCard.js`) menggunakan *props*.
- Menambahkan avatar pengguna dan menampilkan gambar lokal dari folder `assets/moods`.
- Membuat variasi warna bingkai (border) yang dinamis untuk setiap daftar cerita.
